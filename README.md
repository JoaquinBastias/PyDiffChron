# PyDiffChron
Python tools for exploring temperature–time non-uniqueness in diffusion chronometry, including a new multi-element tool for retrieving effective diffusion temperatures and timescales.

## Overview

PyDiffChron contains the numerical models developed for studying the uncertainty and non-uniqueness in diffusion chronometry. The code uses synthetic Ba and Sr concentration profiles in plagioclase to investigate:

- non-uniqueness under isothermal and non-isothermal conditions;
- unrecorded residence time at lower temperatures;
- estimation of effective diffusion temperature using paired-element profile widths;
- recovery of corresponding diffusion timescales without fixing temperature or time a priori.
